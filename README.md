Entry for the [One Word From Your Ex](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2) bounty on [make.fun](https://make.fun).

The program (`main.ts`) writes one word to `/output/entry.txt`:

> Internship

The word an ex would use to describe you: you were their internship — unpaid, temporary, taught them everything they never want again, and glad it's over.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/ex-word-out node main.ts
```
